# A Plus Academy Website

A modern multilingual website for **A Plus Academy**, a private primary school.

## Live Demo

https://raedfriaa25-png.github.io/Aplus-Academy-Website/

## Features

- Modern responsive design
- French and Arabic pages
- Online registration form
- WhatsApp contact integration
- Facebook link integration
- Gallery section
- Smooth animations
- Mobile-friendly layout

## Technologies

- HTML
- CSS
- JavaScript
- GitHub Pages
- FormSubmit

## Project Purpose

This project was created as a real school website for A Plus Academy.  
It presents the school, its values, contact information, registration form, and multilingual support.
